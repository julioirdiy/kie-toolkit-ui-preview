# Pratinjau UI KIE Toolkit

Folder ini berisi pratinjau statis untuk presentasi tampilan. Tidak ada Laravel, database, `.env`, atau file materi asli.

## Yang bisa didemokan

- Tampilan katalog yang responsif di laptop dan ponsel.
- Pencarian dan filter kategori di browser.
- Dialog detail materi.
- Simulasi formulir profil dan pertanyaan tujuan/audiens.

## Batasan

- Formulir tidak mengirim atau menyimpan data.
- Tombol simulasi tidak mengunduh file.
- Ini bukan situs produksi dan bukan pengganti hosting aplikasi Laravel.

## Cara mencoba di laptop

Buka `index.html` di browser. Untuk menerbitkan lewat GitHub Pages, unggah isi folder ini ke repositori baru yang terpisah dari project Laravel. Pastikan `index.html` berada di akar repositori.

Situs GitHub Pages dapat diakses publik. Jangan menambahkan data pribadi, kredensial, atau materi yang belum boleh dibagikan.
